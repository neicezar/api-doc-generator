# Documentação Técnica — https://github.com/spring-guides/gs-rest-service

## Visão Arquitetural
O sistema é composto por camadas que interagem de forma a permitir a manipulação de dados e o atendimento de requisições HTTP. A classe `RestServiceApplication` atua como ponto de entrada para a aplicação, inicializando o contexto e o servidor. O `GreetingController` é responsável por gerenciar as requisições relacionadas a saudações, enquanto a classe `Greeting` serve como um DTO para a transferência de dados de saudação.

## Guia de Endpoints
A aplicação expõe o seguinte endpoint:
- `GET /greeting`: Retorna uma instância da classe Greeting.

## Documentação Técnica

### Greeting
A classe `Greeting` é um DTO (Data Transfer Object) que representa uma saudação. Possui os seguintes campos:
- **id** (Long): Identificação única da saudação.
- **content** (String): Texto da saudação. 

Esta classe é utilizada para transferir dados de saudação entre diferentes partes da aplicação.

### GreetingController
A classe `GreetingController` é responsável por gerenciar requisições HTTP relacionadas ao recurso de saudação. Suas funcionalidades incluem:
- Um método `greeting` que retorna uma instância da classe `Greeting`, respondendo a uma solicitação GET no endpoint `/greeting`. Utiliza um contador atômico para rastrear o número de saudações geradas e um template de String para formatar a mensagem de saudação.

### RestServiceApplication
A classe `RestServiceApplication` é uma aplicação Spring Boot que serve como ponto de entrada para a execução do serviço REST. É anotada com `@SpringBootApplication`, que habilita funcionalidades do framework, como configuração automática, varredura de componentes e suporte a configuração. O método `main` inicia a aplicação, permitindo que o serviço seja executado.

### RestServiceApplication (Duplicata)
A classe `RestServiceApplication` é uma aplicação Spring Boot responsável por inicializar o contexto da aplicação. O método `main` serve como ponto de entrada para a aplicação, iniciando o servidor e permitindo a execução do serviço REST. Não possui campos definidos.
