# Documentação Técnica — https://github.com/spring-guides/gs-rest-service

## Visão Arquitetural
A arquitetura da aplicação consiste em três camadas principais: a camada de dados, a camada de controle e a camada de aplicação. A `Greeting` atua como um Data Transfer Object (DTO) que facilita a transferência de dados relacionados às saudações entre a camada de controle e outras partes da aplicação. O `GreetingController` serve como o controlador REST, gerenciando as requisições feitas ao endpoint `/greeting` e utilizando o `Greeting` para formatar as respostas. Por fim, a `RestServiceApplication` é a classe que inicia a aplicação, configurando o contexto do Spring Boot e permitindo que a aplicação funcione corretamente.

## Guia de Endpoints
### Endpoint
- `GET /greeting`
  - Descrição: Retorna uma saudação. O parâmetro opcional "name" pode ser fornecido para personalizar a saudação.

## Documentação Técnica
### Greeting
A classe `Greeting` é um Data Transfer Object (DTO) que possui os seguintes campos:
- `id`: Um identificador único para a saudação.
- `content`: O conteúdo da saudação.

Esta classe é utilizada para transportar dados nas interações com a API, especialmente em operações de entrada e saída.

### GreetingController
A classe `GreetingController` é um controlador REST responsável por gerenciar as requisições ao endpoint `/greeting`. Ela possui:
- Um campo `template` que define a mensagem de saudação.
- Um campo `counter` que é uma instância de `AtomicLong`, utilizado para rastrear o número de saudações geradas.

O método `greeting` desta classe aceita um parâmetro opcional `name` e retorna um objeto `Greeting` baseado nesse nome, facilitando a personalização das mensagens de saudação.

### RestServiceApplication
A classe `RestServiceApplication` atua como o ponto de entrada da aplicação Spring Boot. Com a anotação `@SpringBootApplication`, ela é responsável por inicializar e configurar automaticamente os componentes essenciais do Spring, preparando o ambiente para que a aplicação funcione. O método `main` é o responsável por executar a aplicação.
