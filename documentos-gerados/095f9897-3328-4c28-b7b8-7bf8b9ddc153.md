# Documentação Técnica — https://github.com/spring-guides/gs-rest-service

## Visão Arquitetural
O projeto implementa o padrão arquitetural MVC (Model-View-Controller). A estrutura do pacote `com.example.restservice` é composta por componentes que exercem papéis distintos: 

- **Model**: Representado pela classe `Greeting`, que encapsula os dados de uma saudação. 
- **View**: A interação com o cliente é realizada através de endpoints definidos em controladores.
- **Controller**: A classe `GreetingController` gerencia as requisições HTTP, atuando como um intermediário e processando as entradas antes de retornar as respostas apropriadas.

Essa separação de responsabilidades facilita a manutenção e a escalabilidade da aplicação, permitindo que os desenvolvedores se concentrem em aspectos específicos sem interferir em outras áreas.

## Guia de Endpoints

### Endpoint: `GET /greeting`
- **Descrição**: Retorna uma saudação personalizada.
- **Parâmetros**:
  - `name` (opcional): Nome a ser utilizado na saudação. O valor padrão é "World".
  
#### Exemplos de Requisição e Resposta
- **Com parâmetro `name`**:
  - Requisição:
    ```
    GET /greeting?name=John HTTP/1.1
    Host: example.com
    ```
  - Resposta:
    ```json
    {
      "id": 1,
      "content": "Hello, John!"
    }
    ```

- **Sem parâmetro `name`**:
  - Requisição:
    ```
    GET /greeting HTTP/1.1
    Host: example.com
    ```
  - Resposta:
    ```json
    {
      "id": 2,
      "content": "Hello, World!"
    }
    ```

## Documentação Técnica

### Pacote: com.example.restservice

#### Descrição do Pacote
O pacote `com.example.restservice` gerencia a interação entre a apresentação e a lógica de negócios, manipulando requisições HTTP relacionadas à entidade `Greeting`.

#### Classes

##### Greeting (DTO)
A classe `Greeting` é um Data Transfer Object (DTO) que encapsula os dados de uma saudação.

###### Campos
- `id` (long): Identificador único da saudação.
- `content` (String): Texto da saudação.

##### GreetingController (CONTROLLER)
A classe `GreetingController` atua como um intermediário entre o cliente e a lógica de negócios, respondendo a requisições relacionadas a cumprimentos.

###### Anotação
- `@RestController`: Indica que esta classe é um controlador que manipula dados REST.

###### Endpoints
- **GET /greeting**: Retorna uma saudação personalizada (conforme descrito na seção de guia de endpoints).

##### RestServiceApplication (DESCONHECIDA)
A classe `RestServiceApplication` é a classe principal da aplicação Spring Boot, responsável por inicializar o contexto da aplicação.

###### Anotação
- `@SpringBootApplication`: Indica que esta é uma aplicação Spring Boot.

###### Métodos
- `public static void main(String[] args)`: Ponto de entrada da aplicação, onde a execução começa. Este método não contém campos definidos e serve para carregar os componentes do Spring.
