# Documentação Técnica — https://github.com/spring-guides/gs-rest-service

## Visão Arquitetural
A API descrita no repositório segue o padrão arquitetural MVC (Model-View-Controller). Nesta configuração, a classe `GreetingController` atua como o controlador responsável por gerenciar as requisições HTTP. Ele processa as entradas recebidas e utiliza o objeto `Greeting`, que representa os dados a serem trocados entre a aplicação e o cliente, para construir as respostas adequadas. A classe `RestServiceApplication` é o ponto de entrada da aplicação, onde o contexto Spring é inicializado e todas as configurações pertinentes são aplicadas para o funcionamento do serviço REST.

## Guia de Endpoints

### Endpoint: `GET /greeting`
- **Descrição:** Retorna uma saudação personalizada.
- **Parâmetros:**
  - `name` (opcional): Nome a ser usado na saudação. Se não fornecido, será utilizado o valor padrão "World".
- **Exemplo de Requisição:**
    ```
    GET /greeting?name=Alice HTTP/1.1
    Host: example.com
    ```
- **Exemplo de Resposta:**
    ```json
    {
      "id": 1,
      "content": "Hello, Alice!"
    }
    ```

- **Exemplo de Requisição sem parâmetro:**
    ```
    GET /greeting HTTP/1.1
    Host: example.com
    ```
- **Exemplo de Resposta:**
    ```json
    {
      "id": 2,
      "content": "Hello, World!"
    }
    ```

## Documentação Técnica

### Pacote: com.example.restservice

#### Descrição do Pacote
O pacote `com.example.restservice` é parte fundamental da arquitetura da API, seguindo o padrão MVC (Model-View-Controller). Ele é responsável por implementar a lógica de controle das requisições HTTP e a representação dos dados. A classe `GreetingController` atua como o controlador, recebendo e respondendo às requisições, enquanto a classe `Greeting` serve como um objeto de transferência de dados (DTO) para facilitar a comunicação entre o controlador e a camada de apresentação. A classe `RestServiceApplication` é a entrada da aplicação, responsável pela inicialização e configuração do contexto do Spring.

#### Classes e Detalhes

##### Greeting (DTO)
A classe `Greeting` representa um objeto de transferência de dados (DTO) que contém as seguintes propriedades:

- **Campos:**
  - `id` (long): Identificador único da saudação.
  - `content` (String): Texto da saudação.

##### GreetingController (CONTROLLER)
A classe `GreetingController` é um controlador REST que expõe o seguinte endpoint:

- **Endpoint: `GET /greeting`**
  - **Descrição:** Retorna uma saudação personalizada.

##### RestServiceApplication (DESCONHECIDA)
A classe `RestServiceApplication` é a classe principal da aplicação e possui as seguintes características:

- **Anotação:**
  - `@SpringBootApplication`: Anotação que indica que esta classe é a aplicação Spring Boot.

- **Métodos:**
  - `public static void main(String[] args)`: Ponto de entrada da aplicação que inicializa o contexto do Spring. Não possui campos definidos e é essencial para o funcionamento da API.
