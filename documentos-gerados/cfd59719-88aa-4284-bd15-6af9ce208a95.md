# Documentação Técnica — https://github.com/spring-guides/gs-rest-service

## Visão Arquitetural
Este projeto Java é estruturado seguindo o padrão arquitetural MVC (Model-View-Controller). A interação entre as camadas é definida da seguinte forma:

- **Modelo (Model)**: A classe `Greeting` atua como um Data Transfer Object (DTO), encapsulando os dados que serão manipulados e transmitidos entre as camadas.
  
- **Controlador (Controller)**: A classe `GreetingController` gerencia as requisições HTTP, interagindo com o modelo `Greeting` e retornando respostas adequadas aos clientes.

- **Inicialização da Aplicação (Application)**: A classe `RestServiceApplication` é responsable pela inicialização da aplicação Spring Boot, que configura e executa o serviço REST, gerenciando o contexto da aplicação.

## Guia de Endpoints
A API expõe um endpoint principal para serviços de saudação:

- **Endpoint:**
  - `GET /greeting`

- **Parâmetros:**
  - `name` (opcional): Nome a ser incluído na saudação. Valor padrão é "World".

- **Exemplo de Requisição:**
  ```
  GET /greeting?name=Alice
  ```

- **Exemplo de Resposta:**
  ```json
  {
    "id": 1,
    "content": "Hello, Alice!"
  }
  ```

## Documentação Técnica

### Pacote: com.example.restservice

#### Descrição do Pacote
O pacote `com.example.restservice` implementa um serviço REST que segue o padrão MVC. A classe `Greeting` representa um DTO para saudações, `GreetingController` gerencia as requisições e respostas HTTP, e `RestServiceApplication` é responsável pela inicialização e execução da aplicação.

#### Classes do Pacote

##### Greeting (DTO)
A classe `Greeting` representa uma saudação e contém os seguintes campos:

- **Campos:**
  - `long id`: Identificador único da saudação.
  - `String content`: Texto da saudação.

- **Métodos:**
  - Getters e Setters para os campos `id` e `content`, permitindo o acesso e a manipulação dos dados.

##### GreetingController (CONTROLLER)
A classe `GreetingController` é o controlador que gerencia as requisições HTTP relacionadas a saudações e expõe a seguinte API:

- **Endpoint:**
  - `GET /greeting`
  
- **Parâmetros:**
  - `name` (opcional): Nome a ser incluído na saudação. Valor padrão é "World".

- **Exemplo de Requisição:**
  ```
  GET /greeting?name=Alice
  ```

- **Exemplo de Resposta:**
  ```json
  {
    "id": 1,
    "content": "Hello, Alice!"
  }
  ```

##### RestServiceApplication (DESCONHECIDA)
A classe `RestServiceApplication` é responsável por iniciar a aplicação Spring Boot:

- **Anotação:**
  - `@SpringBootApplication`: Indica que esta é uma aplicação Spring Boot.

- **Método:**
  - `public static void main(String[] args)`: Ponto de entrada da aplicação onde a execução é inicializada. 

Esta classe não contém campos ou métodos adicionais além do método `main`, e a configuração do ambiente de execução é gerenciada automaticamente pelo Spring Boot por meio das convenções de inicialização padrão.
