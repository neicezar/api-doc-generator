# Documentação Técnica — https://github.com/Throyer/springboot-api-rest-example

## Visão Arquitetural
O projeto é estruturado em camadas típicas de uma aplicação Spring Boot, onde as classes são organizadas em controladores, serviços, repositórios e entidades. Os controladores (como `AuthenticationController`, `RecoveriesController`, `RolesController`, `UsersController`, etc.) são responsáveis por gerenciar as requisições HTTP e interagir com os serviços. Estes serviços (como `AuthenticationService`, `RecoveryService`, `AppUserService`, etc.) contêm a lógica de negócios e utilizam os repositórios para acessar os dados persistidos. Os repositórios (como `UserRepository`, `RoleRepository`, `RecoveryRepository`, etc.) realizam a interação direta com o banco de dados, utilizando entidades que representam as tabelas correspondentes. Assim, as camadas se comunicam entre si, favorecendo uma arquitetura limpa e desacoplada.

## Guia de Endpoints

### `POST /auth`
- **Parâmetros aceitos:**
  - `email` (String, obrigatório)
  - `password` (String, obrigatório)

- **Exemplo de requisição:**
```json
{
  "email": "user@example.com",
  "password": "securepassword"
}
```

- **Exemplo de resposta:**
```json
{
  "user": {
    "id": "123",
    "name": "John Doe",
    "email": "user@example.com",
    "active": true,
    "roles": ["USER"]
  },
  "accessToken": "some.jwt.token",
  "refreshToken": "some.refresh.token",
  "expiresAt": "2023-12-31T23:59:59Z"
}
```

### `POST /auth/refresh`
- **Parâmetros aceitos:**
  - `refreshToken` (String, obrigatório)

- **Exemplo de requisição:**
```json
{
  "refreshToken": "existing.refresh.token"
}
```

- **Exemplo de resposta:**
```json
{
  "accessToken": "new.jwt.token",
  "expiresAt": "2023-12-31T23:59:59Z"
}
```

### `POST /recover`
- **Parâmetros aceitos:**
  - `email` (String, obrigatório)

- **Exemplo de requisição:**
```json
{
  "email": "user@example.com"
}
```

- **Exemplo de resposta:**
```json
{
  "message": "Recovery email sent."
}
```

### `POST /recover/confirm`
- **Parâmetros aceitos:**
  - `email` (String, obrigatório)
  - `code` (String, obrigatório)

- **Exemplo de requisição:**
```json
{
  "email": "user@example.com",
  "code": "123456"
}
```

- **Exemplo de resposta:**
```json
{
  "message": "Recovery code confirmed."
}
```

### `POST /recover/update`
- **Parâmetros aceitos:**
  - `email` (String, obrigatório)
  - `code` (String, obrigatório)
  - `password` (String, obrigatório)

- **Exemplo de requisição:**
```json
{
  "email": "user@example.com",
  "code": "123456",
  "password": "newsecurepassword"
}
```

- **Exemplo de resposta:**
```json
{
  "message": "Password successfully updated."
}
```

### `GET /roles`
- **Exemplo de resposta:**
```json
[
  {
    "id": "1",
    "name": "ROLE_USER",
    "shortName": "USER",
    "description": "Regular user role"
  },
  {
    "id": "2",
    "name": "ROLE_ADMIN",
    "shortName": "ADMIN",
    "description": "Administrator role"
  }
]
```

### `GET /users`
- **Parâmetros aceitos:**
  - `page` (Integer, opcional, padrão: 0)
  - `size` (Integer, opcional, padrão: 10)

- **Exemplo de requisição:**
```
GET /users?page=1&size=5
```

- **Exemplo de resposta:**
```json
{
  "content": [
    {
      "id": "123",
      "name": "John Doe",
      "email": "user@example.com",
      "active": true,
      "roles": ["USER"]
    }
  ],
  "page": 1,
  "size": 5,
  "totalPages": 10,
  "totalElements": 50
}
```

## Documentação Técnica

### MavenWrapperDownloader
- **Campos:**
  - `WRAPPER_VERSION` (String)
  - `DEFAULT_DOWNLOAD_URL` (String)
  - `MAVEN_WRAPPER_PROPERTIES_PATH` (String)
  - `MAVEN_WRAPPER_JAR_PATH` (String)

### HomeController
- Métodos:
  - `index()`: retorna uma String
  - `app()`: retorna uma String
  - `api()`: retorna um objeto do tipo `Hello`

### Main
- **Campos:** Nenhum definido.
- **Métodos:**
  - `main(String args)`: ponto de entrada da aplicação.

### AuthenticationController
- Métodos:
  - `create(CreateAuthenticationWithEmailAndPassword body)`: gera um token JWT, retorna `ResponseEntity<Authentication>`
  - `refresh(CreateAuthenticationWithRefreshToken body)`: gera um novo token JWT, retorna `ResponseEntity<Authentication>`

- **Campos:**

  - `password` (String)
