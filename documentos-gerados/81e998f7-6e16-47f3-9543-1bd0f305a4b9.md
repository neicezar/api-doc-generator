# Documentação Técnica — https://github.com/spring-guides/gs-rest-service

## Visão Arquitetural
O projeto segue o padrão arquitetural MVC (Model-View-Controller), onde a lógica de controle, apresentação e manipulação de dados é separada. Essa estrutura organiza a aplicação em três camadas principais:

- **Model (DTO)**: Representado pela classe `Greeting`, que encapsula os dados da saudação.
- **View (Controller)**: A classe `GreetingController`, que gerencia as requisições e respostas HTTP, expondo os dados para a apresentação.
- **Controller (Aplicação)**: A classe `RestServiceApplication`, que inicializa o contexto da aplicação Spring Boot e serve como o ponto de entrada.

## Guia de Endpoints

### Endpoints Expostos pelo `GreetingController`

#### GET /greeting

Este endpoint retorna uma saudação. Ele aceita um parâmetro opcional de consulta `name`, com o valor padrão "World".

- **Parâmetros:**
  - `name` (opcional): Nome da pessoa a ser saudada. Se não fornecido, o valor padrão será "World".

- **Exemplo de Requisição:**
  ```
  GET /greeting?name=Alice
  ```

- **Exemplo de Resposta:**
  ```json
  {
    "id": 1,
    "content": "Hello, Alice!"
  }
  ```

- **Exemplo sem o parâmetro `name`:**
  ```
  GET /greeting
  ```

- **Exemplo de Resposta:**
  ```json
  {
    "id": 2,
    "content": "Hello, World!"
  }
  ```

## Documentação Técnica

### Pacote: com.example.restservice

#### Papel na Arquitetura
O pacote `com.example.restservice` implementa a lógica de um serviço de saudações dentro da estrutura do padrão MVC. Ele contém definições de dados (DTO), um controlador (Controller) que gerencia requisições e respostas HTTP, e a aplicação que inicializa o contexto do Spring Boot.

#### Classes deste Pacote

##### Greeting (DTO)
A classe `Greeting` é um objeto de transferência de dados que encapsula os dados necessários para representar uma saudação na aplicação.

- **Campos:**
  - `long id`: Identificador único da saudação.
  - `String content`: Texto da saudação.

- **Exemplo de Uso:**
  Ao ser solicitado, um objeto `Greeting` pode apresentar a seguinte estrutura:
  ```json
  {
    "id": 1,
    "content": "Hello, World!"
  }
  ```

##### GreetingController (CONTROLLER)
A classe `GreetingController` é responsável por gerenciar as requisições feitas ao serviço de saudações. Ela expõe um endpoint REST que permite que um cliente obtenha uma saudação formatada.

##### RestServiceApplication (DESCONHECIDA)
A classe `RestServiceApplication` é a entrada principal da aplicação Spring Boot. Ela inicializa o contexto da aplicação e possibilita a execução do serviço.

- **Métodos Relevantes:**
  - `public static void main(String[] args)`: Método que inicia a aplicação Spring Boot. Esta classe não possui campos definidos, atuando como um ponto de arranque para todo o serviço.

## Conclusão
O pacote `com.example.restservice` representa uma implementação simplificada de um serviço REST de saudações, seguindo os princípios do padrão arquitetural MVC, permitindo uma organização eficiente da lógica de controle e manipulação de dados.
