# Documentação Técnica — https://github.com/spring-guides/gs-rest-service

## Visão Arquitetural
O projeto segue o padrão arquitetural MVC (Model-View-Controller), onde as camadas são organizadas de maneira a separar as responsabilidades. A camada de apresentação é representada por `GreetingController`, que é responsável por processar as requisições HTTP e manipular as interações do usuário. A lógica de negócios e os dados são tratados pela classe `Greeting`, que atua como um Data Transfer Object (DTO) para facilitar a transferência de dados. A classe `RestServiceApplication` inicia o contexto da aplicação, mas não se enquadra diretamente nas camadas do MVC. Esta separação promove uma arquitetura mais limpa, facilitando a manutenção e a escalabilidade do sistema.

## Guia de Endpoints
### Endpoints do `GreetingController`
- **GET /greeting**
  - **Descrição**: Retorna uma saudação. Pode personalizar a saudação com um nome opcional.
  - **Parâmetros**:
    - `name` (opcional): String para personalizar a mensagem de saudação. Valor padrão é "World".
  - **Exemplo de Requisição**:
    ```
    GET /greeting?name=Alice
    ```
  - **Exemplo de Resposta**:
    ```json
    {
      "id": 1,
      "content": "Hello, Alice!"
    }
    ```
  - **Exemplo de Requisição (com valor padrão)**:
    ```
    GET /greeting
    ```
  - **Exemplo de Resposta**:
    ```json
    {
      "id": 2,
      "content": "Hello, World!"
    }
    ```

## Documentação Técnica

### Pacote: com.example.restservice

#### Descrição do Pacote
O pacote `com.example.restservice` é responsável pela implementação de uma API REST que segue o padrão arquitetural MVC. Neste contexto, o pacote contém classes que desempenham papéis específicos: o `Greeting` como um Data Transfer Object (DTO) para transferência de dados, o `GreetingController` como a camada de controle que gerencia requisições HTTP e o `RestServiceApplication` que inicia a aplicação. A separação de responsabilidades facilita a manutenção e escalabilidade da aplicação.

#### Classes do Pacote

##### Greeting (DTO)
A classe `Greeting` é um Data Transfer Object que encapsula os dados da saudação. É utilizada para transferir informações entre a camada de apresentação e a camada de serviço.

###### Campos
- `long id`: Identificador único da saudação.
- `String content`: Texto da saudação.

##### GreetingController (CONTROLLER)
A classe `GreetingController` gerencia as requisições HTTP relacionadas a cumprimentos e expõe endpoints para que os usuários possam obter mensagens personalizadas de saudação.

##### RestServiceApplication (DESCONHECIDA)
A classe `RestServiceApplication` é a classe principal da aplicação Spring Boot. É responsável por iniciar o contexto da aplicação.

###### Método
- **main(String[] args)**: Ponto de entrada da aplicação Spring, que inicia a execução da aplicação. Não possui campos ou outros métodos definidos.
