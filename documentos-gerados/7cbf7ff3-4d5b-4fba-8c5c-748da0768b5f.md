# Documentação Técnica — https://github.com/spring-guides/gs-accessing-data-jpa

## Visão Arquitetural
A arquitetura da aplicação consiste em três principais componentes: 

1. **AccessingDataJpaApplication**: É o ponto de entrada da aplicação e configura o contexto do Spring Boot. Ela inicializa a aplicação e configura beans, como o repositório de clientes.

2. **Customer**: Esta classe representa a entidade central do domínio, modelando os dados de um cliente com atributos como nome e sobrenome.

3. **CustomerRepository**: Este é o repositório que fornece as operações de acesso aos dados da entidade Customer, permitindo a busca de clientes por sobrenome e por identificação.

Essas camadas interagem da seguinte forma: a aplicação inicia através da `AccessingDataJpaApplication`, que, ao iniciar, interage com o `CustomerRepository` para manipulação dos dados da entidade `Customer`.

## Guia de Endpoints
O repositório não expõe endpoints REST.

## Documentação Técnica

### AccessingDataJpaApplication
- **Método**: `main(String[] args)`
  - Descrição: Ponto de entrada da aplicação Spring Boot.

- **Método**: `demo(CustomerRepository repository)`
  - Tipo: `CommandLineRunner`
  - Descrição: Método que executa interações específicas com o `CustomerRepository` ao iniciar a aplicação.
  
- **Campo**: `Logger logger`
  - Tipo: `Logger`
  - Descrição: Usado para registrar mensagens de log durante a execução da aplicação.

### Customer
- **Campo**: `id`
  - Tipo: `Long`
  - Descrição: Identificador único do cliente.
  
- **Campo**: `firstName`
  - Tipo: `String`
  - Descrição: Nome do cliente.

- **Campo**: `lastName`
  - Tipo: `String`
  - Descrição: Sobrenome do cliente.

- **Método**: `toString()`
  - Descrição: Retorna uma representação textual do objeto Customer.

- **Método**: `getId()`
  - Descrição: Acessa o atributo id.

- **Método**: `getFirstName()`
  - Descrição: Acessa o atributo firstName.

- **Método**: `getLastName()`
  - Descrição: Acessa o atributo lastName.

### CustomerRepository
- **Método**: `findByLastName(String lastName)`
  - Descrição: Retorna uma lista de clientes com base no sobrenome fornecido.

- **Método**: `findById(long id)`
  - Descrição: Retorna um cliente específico conforme o identificador informado.
