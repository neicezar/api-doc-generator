# Documentação Técnica — https://github.com/Throyer/springboot-api-rest-example

## Visão Arquitetural

O projeto Java descrito segue o padrão arquitetural de camadas tradicionais, que inclui os níveis de controle, serviço e repositório. Essa arquitetura segregada permite a separação de responsabilidades:
- Os **controladores** lidam com a interface e as requisições do usuário.
- Os **serviços** contêm a lógica de negócios.
- Os **repositórios** fazem a comunicação com a base de dados.

Essa organização clara promove a testabilidade da aplicação e facilita a manutenção e expansão do sistema.

## Guia de Endpoints

### Endpoints dos Controladores

#### HomeController
- **GET /**: Retorna uma mensagem padrão da aplicação.
  - **Resposta**: 
    ```
    Bem-vindo à API!
    ```

- **GET /app**: Retorna informações específicas sobre a aplicação.
  - **Resposta**: 
    ```
    Informações sobre a aplicação.
    ```

- **GET /api**: Retorna um objeto `Hello`.
  - **Resposta**: 
    ```json
    {
      "message": "Hello, World!"
    }
    ```

#### UsersController
- **GET /api/users**: Retorna uma lista paginada de usuários.
  - **Parâmetros**: `page`, `size`.
  - **Resposta**: 
  ```json
  {
      "currentPage": 1,
      "totalPages": 10,
      "totalItems": 100,
      "users": [
          {
              "id": 1,
              "name": "João Silva",
              "email": "joao.silva@example.com"
          }
      ]
  }
  ```

- **GET /api/users/{id}**: Exibe informações de um usuário específico.
  - **Exemplo**: `/api/users/1`
  - **Resposta**:
  ```json
  {
      "id": 1,
      "name": "João Silva",
      "email": "joao.silva@example.com"
  }
  ```

- **POST /api/users**: Registra um novo usuário.
  - **Corpo da Requisição**:
  ```json
  {
      "name": "João da Silva",
      "email": "joao.silva@example.com",
      "password": "senhaSegura123"
  }
  ```
  - **Resposta**:
  ```json
  {
      "id": 1,
      "name": "João Silva",
      "email": "joao.silva@example.com"
  }
  ```

- **DELETE /api/users/{id}**: Deleta um usuário.
  - **Exemplo**: `/api/users/1`
  - **Resposta**:
  ```json
  {
      "message": "Usuário deletado com sucesso."
  }
  ```

#### RecoveriesController
- **POST /recoveries/request**: Inicia o processo de recuperação de senha.
  - **Corpo**:
  ```json
  {
      "email": "usuario@example.com"
  }
  ```
  - **Resposta**:
  ```json
  {
      "message": "E-mail de recuperação enviado com sucesso."
  }
  ```

- **POST /recoveries/confirm**: Confirma o código de recuperação.
  - **Corpo**:
  ```json
  {
      "email": "usuario@example.com",
      "code": "123456"
  }
  ```
  - **Resposta**:
  ```json
  {
      "message": "Código de recuperação validado com sucesso."
  }
  ```

- **POST /recoveries/update**: Atualiza a senha do usuário.
  - **Corpo**:
  ```json
  {
      "email": "usuario@example.com",
      "code": "123456",
      "password": "novaSenhaSegura"
  }
  ```
  - **Resposta**:
  ```json
  {
      "message": "Senha atualizada com sucesso."
  }
  ```

#### AuthenticationController
- **POST /auth**: Autentica o usuário com email e senha.
  - **Corpo**:
  ```json
  {
      "email": "user@example.com",
      "password": "password123"
  }
  ```
  - **Resposta**:
  ```json
  {
      "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
  }
  ```

- **POST /auth/refresh**: Atualiza o token de autenticação.
  - **Corpo**:
  ```json
  {
      "refreshToken": "refresh_token_example"
  }
  ```
  - **Resposta**:
  ```json
  {
      "token": "new_jwt_token_example"
  }
  ```

#### RolesController
- **GET /roles**: Retorna uma lista de papéis disponíveis no sistema.
  - **Resposta**:
  ```json
  [
      {
          "id": 1,
          "name": "ADMIN",
          "description": "Administrator role with full access"
      },
      {
          "id": 2,
          "name": "USER",
          "description": "Standard user role with limited access"
      }
  ]
  ```
