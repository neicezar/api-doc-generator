# Documentação da API

## Visão Arquitetural

A arquitetura da API é baseada no padrão REST, onde a separação de responsabilidades é mantida em diferentes camadas:

- **Controladores (Controllers)**: Responsáveis por receber as solicitações HTTP e retornar respostas apropriadas. Eles mapeiam as rotas para os serviços correspondentes.
- **Serviços (Services)**: Contêm a lógica de negócios da aplicação. Os controladores interagem com os serviços para manipulação de dados.
- **Repositórios (Repositories)**: Gerenciam a persistência dos dados, interagindo com a base de dados. São responsáveis por operações de CRUD (Create, Read, Update, Delete).
- **Modelos (Models)**: Representam as entidades do domínio da aplicação. Usualmente mapeadas para as tabelas do banco de dados.
- **Exceções (Exceptions)**: Tratam erros e exceções que podem ocorrer, proporcionando feedback apropriado para o cliente.

Essa estratificação garante uma organização clara e ajuda na manutenção e escalabilidade, além de permitir testes mais eficientes.

## Guia de Endpoints

A API expõe os seguintes endpoints através de seus controladores:

### Endpoints do Controlador de Usuários

- `GET /api/v1/users` - Retorna uma lista de todos os usuários.
- `GET /api/v1/users/{id}` - Retorna um usuário específico pelo ID.
- `POST /api/v1/users` - Cria um novo usuário.
- `PUT /api/v1/users/{id}` - Atualiza os dados de um usuário existente.
- `DELETE /api/v1/users/{id}` - Remove um usuário pelo ID.

### Endpoints do Controlador de Tarefas

- `GET /api/v1/tasks` - Retorna uma lista de todas as tarefas.
- `GET /api/v1/tasks/{id}` - Retorna uma tarefa específica pelo ID.
- `POST /api/v1/tasks` - Cria uma nova tarefa.
- `PUT /api/v1/tasks/{id}` - Atualiza os dados de uma tarefa existente.
- `DELETE /api/v1/tasks/{id}` - Remove uma tarefa pelo ID.

## Documentação Técnica

### Classe User

#### Descrição
Representa um usuário no sistema.

#### Atributos
- `id`: Identificador único do usuário.
- `username`: Nome de usuário.
- `email`: E-mail do usuário.
- `password`: Senha do usuário.

#### Métodos
- `getId()`: Retorna o ID do usuário.
- `getUsername()`: Retorna o nome de usuário.
- `getEmail()`: Retorna o e-mail do usuário.
- `setId(long id)`: Define o ID do usuário.
- `setUsername(String username)`: Define o nome de usuário.
- `setEmail(String email)`: Define o e-mail do usuário.
- `setPassword(String password)`: Define a senha do usuário.

### Classe UserController

#### Descrição
Controlador que gerencia as operações relacionadas a usuários.

#### Métodos
- `@GetMapping("/users")` - Retorna todos os usuários.
- `@GetMapping("/users/{id}")` - Retorna um usuário específico.
- `@PostMapping("/users")` - Cria um novo usuário.
- `@PutMapping("/users/{id}")` - Atualiza os dados do usuário.
- `@DeleteMapping("/users/{id}")` - Remove um usuário.

### Classe Task

#### Descrição
Representa uma tarefa no sistema.

#### Atributos

- `completed`: Status de conclusão.

#### Métodos
- `getId()`: Retorna o ID da tarefa.

- `setId(long id)`: Define o ID da tarefa.
- `setDescription(String description)`: Define a descrição da tarefa.
- `setCompleted(boolean completed)`: Define o status de conclusão.
