# Documentação Técnica — https://github.com/spring-guides/gs-rest-service

## Visão Arquitetural
A aplicação é construída seguindo o padrão arquitetural MVC (Model-View-Controller), permitindo uma clara separação entre a lógica de apresentação e a lógica de negócios. O pacote principal `com.example.restservice` organiza as classes do modelo, controlador e a aplicação, facilitando a manutenção e evolução do sistema.

- **Modelo**: Representado pelo Data Transfer Object (DTO) `Greeting`, que encapsula os dados das saudações.
- **Controlador**: A classe `GreetingController` gerencia as requisições HTTP, processando as entradas e gerando as respostas adequadas, atuando como intermediário entre o modelo e as interações do usuário.
- **Aplicação**: `RestServiceApplication` é responsável por inicializar o contexto Spring Boot, servindo como ponto de entrada da aplicação.

## Guia de Endpoints

### Endpoint: `GET /greeting`
- **Descrição**: Retorna uma saudação com um `id` único e um conteúdo formatado. Se o parâmetro `name` não for fornecido, utiliza o valor padrão "World".
- **Parâmetros de Requisição**:
  - `name` (opcional): Nome a ser incluído na saudação. O valor padrão é "World".

#### Exemplos de Requisição e Resposta

###### Exemplo de Requisição com Parâmetro
```
GET /greeting?name=Alice
```
###### Exemplo de Resposta
```json
{
  "id": 1,
  "content": "Hello, Alice!"
}
```

###### Exemplo de Requisição sem Parâmetro
```
GET /greeting
```
###### Exemplo de Resposta
```json
{
  "id": 2,
  "content": "Hello, World!"
}
```

## Documentação Técnica

### Pacote: `com.example.restservice`

#### Descrição do Pacote
O pacote `com.example.restservice` é parte de uma aplicação Java projetada com o padrão MVC. Ele agrupa classes responsáveis pelo gerenciamento de saudações, promovendo a separação de responsabilidades e facilitando a manutenção.

#### Classes do Pacote

##### `Greeting` (DTO)
A classe `Greeting` é um Data Transfer Object que representa uma saudação.

###### Campos
- `long id`: Identificador único da saudação.
- `String content`: Texto da saudação.

A classe é utilizada para transferir dados relacionados a saudações entre as camadas da aplicação.

##### `GreetingController` (CONTROLLER)
A classe `GreetingController` é um controlador REST que manipula requisições para o endpoint `/greeting`.

###### Campos
- `String template`: Modelo utilizado para formatar a saudação.
- `AtomicLong counter`: Contador utilizado para gerar identificadores únicos.

###### Endpoints
- `GET /greeting`: Retorna uma saudação com um `id` único e um conteúdo formatado, podendo incluir um nome para personalização.

##### `RestServiceApplication` (DESCONHECIDA)
A classe `RestServiceApplication` é a classe principal da aplicação, responsável por inicializar o contexto do Spring Boot.

###### Método
- `public static void main(String[] args)`: Ponto de entrada da aplicação que inicia o contexto Spring. 

Esta classe não apresenta campos adicionais.
