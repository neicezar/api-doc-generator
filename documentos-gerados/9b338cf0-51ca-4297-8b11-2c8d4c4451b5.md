# Documentação Técnica — https://github.com/spring-guides/gs-rest-service

## Visão Arquitetural
A arquitetura da aplicação é baseada no padrão REST, onde a classe `GreetingController` atua como controlador, gerenciando as solicitações HTTP e interagindo com os dados representados pela classe `Greeting`, que serve como um objeto de transferência de dados (DTO). A classe `RestServiceApplication` é a classe principal que inicializa a aplicação Spring Boot. A interação básica ocorre quando um usuário solicita uma saudação através do `GreetingController`, que utiliza a classe `Greeting` para formatar a resposta a ser enviada de volta ao cliente.

## Guia de Endpoints
- **GET /greeting**: Retorna um objeto `Greeting`, que contém uma mensagem personalizada. O endpoint espera um parâmetro de consulta com o nome do usuário para personalizar a saudação.

## Documentação Técnica

### Greeting
A classe `Greeting` funciona como um objeto de transferência de dados (DTO) que encapsula informações sobre uma saudação. A estrutura da classe, embora não detalhada, sugere que seu propósito é transportar dados entre cliente e servidor, sem lógica de negócio própria.

### GreetingController
A classe `GreetingController` é responsável por gerenciar as requisições REST relacionadas a saudações. Ela possui o método `greeting`, que recebe um nome como entrada e retorna um objeto do tipo `Greeting`. Essa classe é fundamental para a interação da API, transformando as entradas do usuário em respostas personalizadas.

### RestServiceApplication
A classe `RestServiceApplication` é a principal classe da aplicação, anotada com `@SpringBootApplication`, que habilita a configuração automática e a varredura de componentes do Spring. O método `main` é o ponto de entrada da aplicação, onde a execução do Spring Boot é iniciada.

### RestServiceApplication
A classe `RestServiceApplication`, semelhante à descrição anterior, é responsável por iniciar a aplicação Spring Boot. Sua anotação `@SpringBootApplication` indica características de configuração e inicialização do ambiente Spring. O método `main` é onde a aplicação é executada, estabelecendo todas as configurações necessárias.
