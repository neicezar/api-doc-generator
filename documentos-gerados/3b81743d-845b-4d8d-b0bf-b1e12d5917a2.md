# Documentação Técnica — https://github.com/spring-guides/gs-rest-service

## Visão Arquitetural
A arquitetura do serviço REST é composta por três camadas principais: a camada de controle, a camada de modelo e a camada de aplicação. 

- **GreetingController**: Essa é a camada de controle que expõe os endpoints REST. Ela gerencia as requisições HTTP e orquestra a comunicação entre a camada de modelo e o cliente.
- **Greeting (DTO)**: Esta classe é um Data Transfer Object que é utilizada para transferir dados entre as camadas. Ela encapsula as informações sobre a saudação, como o ID e o conteúdo.
- **RestServiceApplication**: Esta classe é o ponto de entrada da aplicação, configurando e iniciando o aplicativo Spring Boot.

## Guia de Endpoints
### GET /greeting
- **Método HTTP e Path**: `GET /greeting`
- **Parâmetros Aceitos**:
  - `name`: `String`, opcional, valor padrão: `"World"`
- **Exemplo de Requisição**:
```
GET /greeting?name=John
```
- **Exemplo de Resposta em JSON**:
```json
{
  "id": 1,
  "content": "Hello, John!"
}
```

## Documentação Técnica

### Greeting
- **Campos**:
  - `id`: `long`
  - `content`: `String`

### GreetingController
- **Campos**:
  - `template`: `String`
  - `counter`: `AtomicLong`
- **Métodos**:

### RestServiceApplication
- **Métodos**:
  - `main(String[] args)`: Ponto de entrada da aplicação.
